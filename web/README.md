# Pac-Man Graph Lab (Frontend)

Este diretório contém a aplicação web em React, TypeScript e Phaser 3.

Para a documentação completa do projeto, fundamentação matemática, arquitetura e guia de execução, consulte o [README principal](../README.md).

## Comandos Rápidos

```bash
npm install
npm run dev
npm run build
npm test
```
